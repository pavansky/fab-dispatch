# Support

- **Using the app:** press **?** in Fab Dispatch for the help center, or **/** to ask the assistant.
- **Documentation:** https://pavansky.github.io/fab-dispatch/ (user guide, architecture, API reference).
- **Questions and ideas:** [GitHub Discussions](https://github.com/pavansky/fab-dispatch/discussions).
- **Bugs:** [open an issue](https://github.com/pavansky/fab-dispatch/issues/new/choose). In the app,
  **About & support → Report a problem** prefills your release and browser.
- **Security:** report privately as described in [SECURITY.md](SECURITY.md), not in a public issue.

Best effort, usually within a few days; security reports first. More in the
[support guide](https://pavansky.github.io/fab-dispatch/support/).
