# Support

## Help yourself first

- **In the app:** press **?** for the help center, or **/** to ask the assistant.
- **This site:** the [user guide](guide/index.md) and [FAQ](guide/faq.md).
- **Status:** the app's **About & support** panel (user menu) shows live system status, and the
  health endpoint is public: [`/api/health`](https://fab-dispatch.vercel.app/api/health).

## Ask or report

| You want to | Go to |
|---|---|
| Ask a question or share an idea | [GitHub Discussions](https://github.com/pavansky/fab-dispatch/discussions) |
| Report a problem | [Open an issue](https://github.com/pavansky/fab-dispatch/issues/new/choose); in the app, **About & support → Report a problem** prefills your release and browser |
| Report a security issue | Privately, via the [security policy](project/security.md); please don't open a public issue |
| Onboard a new fab | [Fab onboarding request](https://github.com/pavansky/fab-dispatch/issues/new?template=fab-onboarding.md) |
| Delete your account | Ask in Discussions or an issue; no details needed beyond the request |

## What to expect

This is a maintained portfolio project: issues and questions are answered on a best-effort basis,
usually within a few days. Security reports get priority.

## Useful to include

The release and build (shown in **About & support**), what you did, what you expected, and any
**request id** from an error message.
