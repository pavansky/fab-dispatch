# Support and feedback

## About & support

Open the user menu (your initial, top right) and choose **About & support**. It shows which version
you're running (the release and build), whether every system is operational, and every link below.

## Report a problem

**About & support → Report a problem** opens a GitHub issue already filled in with your release,
build, page and browser. Add what you did and what you expected. If an error showed a **request id**,
include it.

## Ask a question

Ask the assistant first (**/**). For anything else, use GitHub Discussions, linked from
**About & support**.

## Rate an answer

Every assistant answer has 👍 and 👎. A 👎 lets you say what was wrong. Ratings are kept for 180
days with your user id (not your email) and are how the assistant's answers get better.

## Documentation

The documentation site has this user guide, plus the architecture, the algorithms and their
analysis, design decisions, operations and an interactive API reference. It's linked from
**About & support**, and the API reference is also at `/api/docs` on the app.

## Security and privacy

Report security issues privately through the security policy, never in a public issue. The privacy
page lists what's stored and for how long; to delete your account, ask through support.
