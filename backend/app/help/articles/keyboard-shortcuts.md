# Keyboard shortcuts

Shortcuts work anywhere except while you're typing in a field.

| Key | Action |
|---|---|
| **?** | Open help |
| **/** | Ask the assistant |
| **1** – **6** | Overview, Floor plan, Schedule, Workforce, Live dispatch, Benchmark |
| **Esc** | Close help, the assistant, menus or the controls drawer |
| **Tab**, **Enter** | Move to a job or engineer on the floor plan and inspect it |
